# traceroute-python

Простая утилита traceroute для командной строки, написанная на Python. Позволяет трассировать сетевые пути с использованием различных протоколов.

## Возможности

- ✅ Поддержка IPv4
- ✅ Работа через ICMP + указание SEQ
- ✅ Вывод таблицы трассировки с временем ответа
- ✅ Посылать N запросов [по умолчанию N=3]
- ✅ Задание интервала времени между запросами
- ✅ Задание таймаута ожидания
- ✅ Задание максимального TTL
- ✅ Задание размера пакета [по умолчанию 40]
Дополнительно:
- ✅ Поддержка протокола UDP
- ✅ Поддержка протокола TCP
- ✅ Вывод с автономной системой

## Установка

### Требования

- Python 3.12 или выше
- Poetry (для управления зависимостями)

### Установка проекта

1. Клонируйте репозиторий (замените `/path/to/your/projects` на абсолютный путь к директории, где вы хотите разместить проект):
   ```bash
   git clone https://github.com/MatrikSer/traceroute.git /path/to/your/projects/traceroute
   cd /path/to/your/projects/traceroute
   ```

2. Создайте и активируйте виртуальное окружение (опционально, но рекомендуется):
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # для Linux/Mac
   # или
   .venv\Scripts\activate     # для Windows
   ```

3. Установите зависимости с помощью Poetry:
   ```bash
   poetry install
   ```

## Запуск

Проект запускается через Poetry:

```bash
traceroute [аргументы]
```

## Использование

### Основные аргументы

- `ip` - обязательный аргумент, IP адрес для трассировки (например, `8.8.8.8`)
- `protocol` - протокол (icmp, tcp, udp)
- `-t` - таймаут в секундах, по умолчанию 2
- `-n` - количество запросов (проб на hop), по умолчанию 3
- `-mt` - максимальный TTL, по умолчанию 30
- `-i` - интервал между запросами в секундах, по умолчанию 0
- `-s` - размер пакета, по умолчанию 40 (для ICMP)
- `-p` - порт, по умолчанию 53
- `-v` - verbose вывод (дополнительная информация, номер автономной системы)

### Примеры использования

#### Простая ICMP трассировка

```bash
traceroute 1.1.1.1 icmp
```

#### TCP трассировка с кастомным портом

```bash
traceroute 1.1.1.1 tcp -p 53
```

#### UDP трассировка с большим TTL и интервалом между запросами

```bash
traceroute 1.1.1.1 udp -mt 20 -i 1 -v -n 5 -p 33434
```

#### Кастомный размер пакета и таймаут

```bash
traceroute 1.1.1.1 icmp -s 64 -t 1 -n 5
```

## Функции

Проект состоит из следующих основных модулей:

- `main.py` - точка входа приложения
- `parser.py` - парсер аргументов командной строки
- `traceroute.py` - основной класс логики traceroute, реализация протоколов
- `router.py` - модель данных для хранения информации о hops

Клиент поддерживает:
- IPv4 трассировку
- Протоколы ICMP, TCP, UDP
- Ограничение по TTL (max hops)
- Временные интервалы между запросами
- Определение автономных систем (ASN) через whois
- Verbose вывод с автономной системой
