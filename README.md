### Описание.

Необходимо реализовать свой traceroute с возможностью отправки пакетов по ICMP, TCP или UDP.

Утилита должна запускаться следующим образом:

traceroute [OPTIONS] IP_ADDRESS {tcp|udp|icmp}

Опции [OPTIONS] должны быть следующие:

* -t — таймаут ожидания ответа (по умолчанию 2с)
* -p — порт (для tcp или udp)
* -n — максимальное количество запросов
* -v — вывод номера автономной системы для каждого ip-адреса

Пример запуска:
traceroute -p 53 1.1.1.1 tcp


В ответ утилита должна выдавать информацию о маршруте в формате:
NUM IP [TIME,ms]

Где NUM - порядковый номер, с 1.

Если задана опция -v, вывод содержит колонку [AS] с номером автономной системы. Номер автономной
системы следует узнавать с помощью протокола whois

Если истёк таймаут, вместо IP следует писать "*"


### Примеры Whois запросов

$ nc whois.arin.net 43
n + 9.9.9.9

$ nc whois.apnic.net 43
-V Md5.5.7 1.1.1.1

Диапазоны адресов и информацию о формате запросов следует искать на сайтах организаций,
ответственных за IP-адреса. Пример:

https://www.apnic.net/manage-ip/manage-resources/address-status/apnic-resource-range/
