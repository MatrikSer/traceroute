# traceroute-python

Простая утилита traceroute для командной строки, написанная на Python с использованием Scapy. Позволяет трассировать сетевые пути с использованием протоколов ICMP и TCP.

## Возможности

- ✅ Поддержка IPv4 и IPv6
- ✅ Работа через ICMP
- ✅ Работа через TCP
- ✅ Вывод таблицы трассировки с временем ответа
- ✅ Посылать N запросов на каждый hop [по умолчанию N=3]
- ✅ Задание интервала времени между запросами
- ✅ Задание таймаута ожидания ответа
- ✅ Задание максимального TTL
- ✅ Задание размера пакета [по умолчанию 40 байт]
- ✅ Задание порта для TCP соединений [по умолчанию 53]

## Установка

### Требования

- Python 3.12 или выше
- Poetry (для управления зависимостями)

### Установка проекта

1. Клонируйте репозиторий (замените `/path/to/your/projects` на абсолютный путь к директории, где вы хотите разместить проект):
   ```bash
   git clone https://github.com/MatrikSer/traceroute.git /path/to/your/projects/traceroute
   cd /path/to/your/projects/traceroute
   ```

2. Создайте и активируйте виртуальное окружение (опционально, но рекомендуется):
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # для Linux/Mac
   # или
   .venv\Scripts\activate     # для Windows
   ```

3. Установите зависимости с помощью Poetry:
   ```bash
   poetry install
   ```

## Запуск

Проект запускается через Poetry:

```bash
traceroute <адрес> <протокол> [опции]
```

## Использование

### Основные аргументы

- `address` - обязательный аргумент, IP адрес или домен для трассировки (например, `8.8.8.8` или `google.com`)
- `protocol` - протокол (icmp или tcp)

### Опции

- `-t` - таймаут в секундах, по умолчанию 2
- `-n` - количество запросов (проб на hop), по умолчанию 3
- `-mt` - максимальный TTL, по умолчанию 30
- `-i` - интервал между запросами в секундах, по умолчанию 0
- `-s` - размер пакета в байтах, по умолчанию 40
- `-p` - порт, по умолчанию 53, используется для TCP трассировки

### Примеры использования

#### Простая ICMP трассировка

```bash
traceroute 1.1.1.1 icmp
```

#### TCP трассировка с кастомным портом

```bash
traceroute google.com tcp -p 80
```

#### Трассировка с увеличенным таймаутом и интервалом

```bash
traceroute 1.1.1.1 icmp -t 5 -i 1 -mt 20
```

#### Кастомный размер пакета

```bash
traceroute 192.168.1.1 icmp -s 64 -n 5
```

#### IPv6 трассировка

```bash
traceroute 2001:4860:4860::8888 icmp
```

## Архитектура

Проект состоит из следующих основных модулей:

- `main.py` - точка входа приложения, инициализация и запуск traceroute
- `parser.py` - парсер аргументов командной строки с помощью argparse
- `traceroute.py` - основной класс логики traceroute, реализация протоколов ICMP и TCP
- `router.py` - Pydantic модель для хранения информации о каждом hop

### Класс Traceroute

Основной класс реализует следующие возможности:

- Анализ адреса (IP или домен) и определение версии протокола (IPv4/IPv6)
- Создание пакетов для ICMP и TCP
- Отправка пакетов с увеличивающимся TTL
- Анализ ответов и определение завершения трассировки
- Хранение результатов в списке Router объектов
